- source_spec: `docs/implementation-artifacts/spec-1-6-issue-and-resolve-the-client-identity.md`
  summary: Every API request will resolve the Client Identity twice — once in middleware, once in the route handler — unless the resolved `ownerId` is forwarded upstream.
  evidence: `middleware.ts` resolves on every matched request to enforce AC4's `401`, and the route handlers of Epics 2-5 must resolve again to get the `ownerId` their repository calls are scoped by.
