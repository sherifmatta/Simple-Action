What this screen fixes

  • Input pinned top — placeholder what needs doing?, thin rounded plus icon in accent #2680EB, row-radius 14px, its own soft shadow so it reads as a sub-surface of the card.
  • Filter tabs — inset segmented control: recessed track #EDEEF7 with an inner shadow, raised white selected chip, label #1B65C2. Three tabs, equal width, visible from first run.
  • Rows — each Todo is its own white sub-surface, radius 14px, 9px gutter, 50px minimum height. Newest-first.
  • Completed — mint #C3E9D7 + filled blue checkmark + strikethrough in #5F5F7A, all three at once.
  • Delete on pointer devices — trailing icon revealed on row hover only. Touch uses swipe-to-reveal; both are mirrored by a keyboard path. See key-delete.html.
  • Banned — no synonym for Completed appears anywhere; the filter view name matches the Completion Status value exactly. No greeting header, stat tiles, categories, sub-tasks, notification bell, timestamps, FAB or second screen.
