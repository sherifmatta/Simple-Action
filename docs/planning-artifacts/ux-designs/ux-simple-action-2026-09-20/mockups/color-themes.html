Simple Action — colour theme comparison

Four complete themes for the same single screen. The ground, the white card, the mint completed surface, the blue action accent, Poppins, the radii and the light-only mode are locked and identical in all four. What changes is the neutral/text ramp, the danger hue, the filter-tab treatment and the focus ring.

Every screen shows the same content in the same state: input pinned at top, a populated error banner beneath it, Active selected, three rows, and a separate empty-state panel for Completed.
